SecApp - サイバーセキュリティ学習アプリ

同じ機能を持つ 脆弱版サイト（脆弱版アプリ）と 対策版サイト（対策版アプリ）を並べて触り、コードの差分から脆弱性対策の勘所を学べる Spring Boot アプリです。

脆弱性解説 (/docs) を見る 脆弱版サイトへ 対策版サイトへ

脆弱版サイト

SQL 文字列連結、平文パスワード、CSRF 無防備、th:utext による XSS、IDOR、自前 Cookie 認証 — お手本のように脆弱です。

/vulnerable/posts へ

対策版サイト

パラメータ化クエリ、BCrypt、Spring Security、CSRF トークン、オーナー判定、セッション ID 再生成 — 同じ機能を安全に。

/secure/posts へ

学習の流れ

  1. まず 脆弱性解説 (/docs) を読み、攻撃の概念をつかむ
  2. 脆弱版サイトで実際にペイロードを投入して攻撃を成立させる
  3. 対策版サイトで同じペイロードを試し、なぜ通らないかを確認する
  4. ソースコードの vulnerable/ パッケージと secure/ パッケージを diff で比較する

用語のメモ: ヘッダ上段の「サイト」は教材全体の入口（ホーム／解説／脆弱版／対策版）、 ヘッダ下段の「アプリ」はその中で開いている脆弱版／対策版アプリ内の操作を指します。
