脆弱性解説

各脆弱性ごとに「攻撃ペイロード例」と「VULNERABLE / SECURE の実装の違い」をまとめています。

共通の前提（手順を試す前に）

  1. アプリにアクセスできること。 例: ブラウザで http://localhost:8080 を開き、トップページが表示される。
  2. 手順の「脆弱版」は URL が /vulnerable/... の画面です。対策版は /secure/...。まず脆弱版で挙動を確認し、同じ操作を対策版で試して「防げる」ことを確認するのがおすすめです。
  3. 初期ログイン情報（初期データ投入直後の例。ID は Vulnerable 版のユーザ一覧でも確認できます）:
    ユーザー名パスワード役割想定 ID（参考）
    adminadmin123ADMIN1
    alicewonderlandUSER2
    bobbuilderUSER3
  4. 手順内の http://localhost:8080 は、環境に合わせてホストやポートを読み替えてください。
